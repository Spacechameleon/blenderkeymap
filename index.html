01

Aktives Element

Wenn man in Blender mehrere Objekte oder Elemente auswählt, fällt auf, dass alle die gleiche Markierung erhalten und ein Objekt oder Element etwas hervorsticht.

Das ist das sogenannte Active Object/Element.

Grundsätzlich sieht man nur die Werte, Modifier etc. des aktiven Objekts und wenn man diese Werte in den Menüpunkten verändert, ist nur das aktive Element betroffen.

Man wählt ein neues Element als das aktive Element aus, indem man innerhalb der momentanen Auswahl die Shift-Taste gedrückt hält.

Shift + -Innerhalb einer Auswahl ein neues aktives Element auswählen
Alle Werte gleichzeitig ändern

Wenn man alle Objekte gleichermaßen anpassen möchte, muss man die Alt-Taste gedrückt halten. Das funktioniert für viele Blender-Buttons, aber nicht für alle.

Hinweis: Die Modifier müssen alle den gleichen Namen besitzen, wenn man die Alt-Taste benutzen möchte.
Alt + -Ändert die Werte in diesem Block für alle ausgewählten Objekte
Alt + -Verschiebt die Werte in diesem Block gleichmäßig für alle ausgewählten Objekte
Verlinkung

Man kann auch noch weitere Eigenschaften vom aktiven Objekt auf andere übertragen, z.B. Materialien, Modifier oder auch alle Transforms gleichzeitig.

Object → Link/Transfer Data

Apply Transforms

Werte in Geometrie überführen

Transform-Werte lassen sich jederzeit fest in die Geometrie schreiben — das hat spürbare Auswirkungen auf viele andere Bereiche.

01 Apply Transforms
01

Apply Transforms

Grundsätzlich können alle Transforms (Position, Rotation und Skalierung) – angewendet werden Apply.

Dabei werden die aktuellen Werte fest in die Geometrie des Objekts geschrieben. Die Transform-Werte werden anschließend auf 0, 0, 0 (Position/Rotation) bzw. 1, 1, 1 (Skalierung) zurückgesetzt.

In der Praxis wird am häufigsten die Skalierung, etwas seltener die Rotation und nur selten die Position angewendet. Statt die Position anzuwenden, wird häufig der Origin direkt verschoben.

1. Form & Werte

Ein 3D-Objekt besteht aus seiner reinen Form (Geometrie) und seinen Transform-Werten, die im Objekt-Modus gespeichert werden.

2. Transform

Wenn man beispielsweise im Objekt-Modus skaliert, ändert sich nicht die Geometrie, sondern es ändern sich nur die Skalierungswerte.

In diesem Beispiel bleibt die Geometrie des Würfels erhalten, obwohl er optisch wie ein flacher Quader aussieht. Diese Geometrie wird in Blender als Mesh Data gespeichert.

Besonders die Skalierung hat Auswirkungen auf viele andere Bereiche innerhalb von Blender, z.B. können Physiksimulationen doppelt so schnell ablaufen, UVs nicht richtig ausgegeben werden und Sculpting-Brushes verzerrt werden.

3. Apply Transforms

Dieser Vorgang schreibt die Werte in die Geometrie.

Auch wenn das Objekt erst einmal unverändert aussieht, so ist für Blender erst jetzt aus dem Würfel ein flacher Quader geworden.

Mit uniformer Skalierung (z. B. 1,1,1 oder 2,2,2) verhalten sich dieselben Modi wieder wie meistens gewünscht.

Strg + A-Öffnet das Apply Transforms Menü
Mit uniformer Skalierung (z. B. 1,1,1 oder 2,2,2) verhalten sich dieselben Modi wieder wie meistens gewünscht.
-
Verzichtet man auf "Apply Scale", zeigen sich die Anomalien, beispielsweise unregelmäßige Kantenlängen beim Inset im Edit Mode, langgezogene Brushes im Sculpt Mode und unregelmäßige Kantenlängen im Bevel-Modifier.

Im Editiermenü gibt es jede Menge neue Werkzeuge in der Werkzeugleiste. Grün bedeutet, dass Geometrie hinzugefügt wird und rosa, dass sie verformt wird.
